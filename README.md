# Deep Learning & Neural Networks Portfolio

A collection of **45 Jupyter notebooks across 15 learning topics**, documenting hands-on work with neural-network fundamentals, TensorFlow/Keras, computer vision, sequence modeling, generative models, optimization, and model-export workflows.

My background is in **Plasma Physics (M.Sc.)**. This portfolio demonstrates applied deep learning practice and a progression from foundational concepts to more advanced model-development exercises. The notebooks are educational exercises, not claims of production deployment or validated real-world model performance.

## Skills illustrated

- **Neural network foundations:** perceptrons, MLPs, nonlinear activations and backpropagation.
- **Frameworks and training:** Python, NumPy, TensorFlow/Keras, training loops, regularization and optimization.
- **Computer vision and sequences:** CNN-based image classification, RNN/LSTM and transfer-learning exercises.
- **Generative deep learning:** autoencoders, variational autoencoders and GAN variants.
- **Experimentation:** hyperparameter search, including Bayesian approaches and Optuna examples, plus reproducibility workflows.
- **Model handoff:** model saving, export and deployment-oriented demonstrations; some workflows have dependency-dependent fallbacks.

## How to use

1. Click the **Open in Colab** badge for the exercise level you want.
2. Install the notebook-specific dependencies when required. Some examples download datasets or require additional libraries; successful execution depends on the environment.
3. Follow the notebook cells and inspect the exercise outputs. Saved outputs are not substitutes for reproducing the results.
